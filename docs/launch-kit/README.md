## Ordre conseillé

1. **Lis `textes-de-presentation.md` §1** : les faits à ne jamais déformer. Tout le reste en
   découle.
2. **Ouvre `calendrier.md`** et suis-le semaine par semaine. Il reprend tes tâches de
   docs/acquisition.md §5 et le calendrier du §6.
3. **Semaine 1** : crée les comptes de la marque (même nom partout), mets les liens de bio avec
   leur `utm_source`, ouvre le compte Trustpilot, tourne les premières vidéos.
4. **Semaines 2 et 3** : inscris le site dans les annuaires (`annuaires.md`), en commençant par
   ceux qui ont une file d'attente, puis lance-toi sur Product Hunt (`product-hunt.md`).
5. **Ensuite, chaque semaine** : 3 vidéos, 2 posts LinkedIn, 3 partages utiles dans les
   communautés et, à partir de janvier, 10 e-mails de partenariat.
6. **Chaque lundi** : regarde le tableau « Provenance » de l'administration. Il compte les visites,
   CV créés, comptes et achats par `utm_source` : c'est lui qui dit quels canaux méritent ton
   temps.

## Les règles du kit

- **Rien d'inventé** : pas de statistique, pas de témoignage, pas de promesse d'embauche. Les
  passages entre [crochets] sont à remplir avec ce qui est vrai pour toi, ou à supprimer.
- **Transparence** : le premier CV est gratuit (avec une petite mention sur le PDF), les outils
  avancés sont payants. On le dit à chaque fois.
- **Divulgation** : dans les communautés, tu dis toujours que tu es le créateur du site.
- **Pas d'achat de votes, pas de faux avis, pas de spam.**
- **Un lien par plateforme**, toujours le même, pour que les chiffres soient comparables.

## Décisions qui t'appartiennent

Elles sont rappelées dans les fichiers concernés :

1. **Date du lancement sur Product Hunt** : mercredi 16 décembre 2026 proposé, ou mardi 12 janvier
   2027 si la préparation n'est pas prête (`product-hunt.md` §1).
2. **Nom sur les sites anglophones** : « My CV in 30 Seconds » conseillé (nom de la version
   anglaise), ou « Mon CV en 30 Secondes ».
3. **Annuaires payants** (BetaList, There's An AI For That, Toolify) : non prévus au budget actuel
   de 0 €.
4. **Liens retour obligatoires** demandés par certains annuaires gratuits : à accepter ou non.
5. **Codes de réduction pour les partenaires** : seulement si tu le décides plus tard.
6. **Contenus pour les collégiens (stage de 3e)** : le public a environ 14 ans. Fais vérifier par
   ton juriste les conditions d'âge pour créer un compte ; en attendant, le kit met en avant les
   guides, lisibles sans compte, et s'adresse aussi aux parents.

situation du 25/11/2026 : si un prix ou une fonction du site change, demande-moi de mettre le kit
à jour avant de publier.
